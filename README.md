# Чиллзон — союз гильдий

Аддон для общего чата, состава и согласованных переходов между «Чиллзон» и «Чиллзон Навсегда» в WoW Forever.

[Релизы](https://github.com/Azired/ChillZoneUnion/releases) · [Полная инструкция](README.txt) · [Модель доверия и ограничения](SECURITY.txt)

## Установка

1. В разделе **Assets** нужного релиза скачайте ZIP `ChillZoneUnion` с номером версии.
2. Закройте игру и распакуйте папку `ChillZoneUnion` в `World of Warcraft\_forever_\Interface\AddOns\`.
3. Включите аддон в игре. Окно открывается командой `/cz` или кнопкой CZ у миникарты.

Для общего чата участникам нужен установленный аддон. Первую связь один раз подтверждают главы или офицеры после проверки полного имени. Затем аддон автоматически выбирает связных среди глав, офицеров и персонажей с игровым званием **«Ветеран»**, обнаруженных через подтверждённое соединение. Назначать и сопрягать каждого вручную не требуется. Для работы нужен хотя бы один такой игрок онлайн в каждой гильдии.

Если онлайн остались только ветераны, уже настроенные клиенты продолжают поддерживать связь. **Новой установке без доверенных настроек нужен настроенный глава или офицер своей гильдии онлайн.** Ветеран не подтверждает новые внешние контакты и не передаёт начальное доверие другим участникам.

## Версия 0.7.1-beta

Вкладка «Общий чат» показывает новые обычные сообщения `/г` своей гильдии даже при единственной установке аддона и без настроенной связи. Аддон получает их из игровых событий, поэтому отправителям своей гильдии он для этого не нужен. Сообщения, написанные до загрузки аддона, не восстанавливаются из обычного окна чата. При обычной доставке копия от связного обновляет ту же строку; одинаковые сообщения подряд остаются отдельными. В обычном окне WoW дополнительные копии не печатаются.

Окно использует штатные рамки и вкладки клиента: оформление Forever применяется самим клиентом. Значок CZ размещён в круглом портрете, вкладки находятся под окном, список и поля оформлены как стандартные панели игры. Сохранены поиск, сортировка, общий чат, статистика классов и переходы. Выбранная вкладка отмечается, а скрытое поле ввода освобождает клавиатуру.

Короткая русская команда `/чз` сохранена: без текста она открывает окно, с текстом отправляет сообщение в общий чат. Версия совместима с 0.6.0-beta–0.7.0-beta; соединение и настройки сохраняются. После замены файлов достаточно `/reload`.

Пользовательский архив по-прежнему содержит 23 файла аддона, без `Tests` и скриптов разработчика. Тесты остаются в исходниках и запускаются в GitHub Actions. Материалы первой публикации на CurseForge (0.6.2) находятся в [Publishing/CurseForge](Publishing/CurseForge/README.md).

Главы и офицеры определяются по игровым правам. Участники со званием «Ветеран» также автоматически поддерживают связь. Первоначальную настройку и управление доверием выполняют главы и офицеры.

При выходе связного или утрате подходящего звания выбирается другой доступный кандидат. Актуальность полномочий проверяется перед служебной отправкой. Уже поставленный в очередь PING прежнего кандидата не должен переключать работающую связь. Если подходящих связных онлайн с одной стороны нет, связь приостанавливается до их возвращения.

При переходе с 0.5 и более ранних версий обновиться должны все участники, а первое соединение гильдий нужно подтвердить заново. При обновлении с версий 0.6 и 0.7 повторная настройка не требуется. Все связные, включая ветеранов, остаются доверенными операторами. Перед массовой установкой нужна проверка двух настоящих игровых клиентов. Подробности — в [примечаниях к релизу](.github/releases/0.7.1-beta.md) и [SECURITY.txt](SECURITY.txt).

## Проверки и сборка

GitHub Actions проверяет согласованность версий и запускает обе группы тестов на Lua 5.1. После успешных проверок версия без опубликованного релиза собирается в ZIP из 23 файлов аддона. Папка `Tests`, инструменты сборки и материалы страницы CurseForge в пользовательский архив не входят. Перед публикацией проверяются commit тега и контрольная сумма загруженного архива.

Локальная проверка состава пакета: `pwsh ./tools/package.ps1 -ValidateOnly`.
Локальная сборка: `pwsh ./tools/package.ps1`. Архив появится в `build/`.
Обе группы тестов с установленным Lua 5.1: `sh ./tools/test.sh` (в Windows — `wsl -d Ubuntu -- sh tools/test.sh`). Скрипт запускает именно текущий checkout независимо от имени его папки.
