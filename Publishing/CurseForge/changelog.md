## 0.6.2-beta

- Prepared the public package for CurseForge: 23 addon files in a single `ChillZoneUnion` folder.
- Removed the developer-only `Tests` folder and test runner scripts from the installable ZIP. Tests remain in the source repository and continue to run before packaging.
- Added project description, publication instructions and updated documentation.
- No gameplay, connection protocol or trust schema changes. Existing 0.6.0 and 0.6.1 connections and settings are preserved, including automatic guild master, officer and Veteran relays and the `/чз` shortcut.

This remains a beta build. A live test between the two guilds is required before a wider rollout.
